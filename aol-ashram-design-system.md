# Дизайн-система «Ашрам Искусства Жизни»

Цель: передать атмосферу Бангалорского ашрама Art of Living через цвета, типографику и компоненты интерфейса, чтобы пользователь ощущал виртуальное погружение в пространство ашрама.[web:42][web:43][web:48][web:51]

---

## 1. Образ и принципы

- Бренд Art of Living ассоциируется с восходящим солнцем, тёплыми жёлто‑оранжевыми оттенками и мягкими природными тонами.[web:42][web:43]
- Архитектура Бангалорского ашрама — светлый камень, бежево‑коричневые поверхности, бело‑терракотовые купола и зелень холмов.[web:48][web:51]
- В приложении избегаем «кислотных» и слишком контрастных сочетаний, чтобы не нарушать состояние спокойствия.

Принципы:
- Фон и основные поверхности — светлые, тёплые, близкие к стенам и мрамору ашрама.
- Главный акцент — мягкое солнце ашрама (смягчённый фирменный жёлтый логотипа).
- Вторичные акценты — терракота (крыши, купола) и зелень (сады и холмы).
- Вода/Ганга — поддерживающий медитативный цвет, не основной бренд‑акцент.

## 2. Foundation‑палитра

### 2.1. Базовые цвета «Ашрам»

```text
Нейтральные (стены, мрамор, полы):
- Ashram White     #F9F6EE  (главный фон)
- Ashram Cream     #F2E5CF  (карточки, вторичные поверхности)
- Ashram Beige     #E0CCAA  (бордеры, разделители, тёплый фон секций)
- Ashram Brown     #9B7750  (декоративный текст, иконки)

Солнце и терракота:
- Ashram Sun 500   #FFE15A  (основной солнечный акцент)
- Ashram Sun 600   #F9C93A  (hover для акцентов)
- Ashram Sun 700   #E3A921  (active, тонкие линии, иконки)
- Terracotta 500   #C6744A  (терракотовые элементы мантрапа/крыш)
- Terracotta 600   #A95C37

Зелень и вода:
- Ashram Green 500 #5F8C57  (деревья, холмы)
- Ashram Green 600 #476842
- Ganga 500        #3E7C78  (вода/Ганга)

Текст:
```

## 3. Semantic‑токены цвета

### 3.1. Карта семантических токенов

```css
:root {
  /* Фон и поверхности */
  --color-bg:             #F9F6EE; /* Ashram White */
  --color-surface:        #F2E5CF; /* Ashram Cream */
  --color-surface-alt:    #FFFFFF;
  --color-surface-muted:  #E0CCAA; /* тёплая подложка для секций */
  --color-border-subtle:  #E0CCAA;
  --color-border-strong:  #C8AE87;

  /* Текст */
  --color-text:           #2A302A;
  --color-text-muted:     #747B72;
  --color-text-faint:     #A3A89F;
  --color-text-on-accent: #251E0E; /* тёмный текст на светлом солнечном фоне */

  /* Основной акцент: Солнце ашрама */
  --color-primary:        #FFE15A; /* Ashram Sun 500 */
  --color-primary-hover:  #F9C93A;
  --color-primary-active: #E3A921;
  --color-primary-soft:   #FFF6CB; /* фон для чипов/бэджей */

  /* Второй акцент: терракота */
  --color-secondary:        #C6744A;   /* Terracotta 500 */
  --color-secondary-hover:  #A95C37;
  --color-secondary-soft:   #F4D0BA;

  /* Природа: зелень и вода */
  --color-green:          #5F8C57;  /* Ashram Green 500 */
  --color-green-soft:     #D5E4D1;
  --color-water:          #3E7C78;  /* Ganga 500 */
  --color-water-soft:     #D0E2DF;

  /* Статусы */
  --color-success:        #5F8C57;
  --color-error:          #B8616F;
}
```

### 3.2. Правила использования

- `--color-primary` (Ashram Sun) — главный цвет действия (CTA‑кнопка «Начать медитацию», ключевые подтверждения).
- `--color-secondary` (Terracotta) — второстепенные акценты: заголовки блоков, разделители, ссылки «Подробнее об ашраме».
- `--color-green` и `--color-water` — поддерживающие акценты (иконки, небольшие элементы), не более одного из них активно на одном экране.
- На одном экране допускается **не более двух сильных акцентных цветов**, чтобы интерфейс оставался спокойным.

## 4. Типографика

### 4.1. Шрифтовые семейства

- `--font-display` — брендо‑ориентированный шрифт для крупных заголовков:
  - опционально фирменный скриптовый шрифт Art of Living / элегантный serif типа `DM Serif Display`.
- `--font-body` — основной UI‑шрифт, спокойный sans‑serif с хорошей читаемостью:
  - `Work Sans`, `Inter`, `General Sans` или аналогичный.

Пример токенов:

```css
:root {
  --font-display: 'DM Serif Display', 'Georgia', serif; /* или брендовый AOL Script для логотипа */
  --font-body:    'Work Sans', system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
}
```

### 4.2. Размеры и иерархия

```css
:root {
  --font-size-xs:  12px; /* подписи, метки */
  --font-size-sm:  14px; /* кнопки, вторичный текст */
  --font-size-md:  16px; /* основной текст */
  --font-size-lg:  20px; /* подзаголовки */
  --font-size-xl:  24px; /* основные заголовки */
  --font-size-2xl: 30px; /* welcome/hero заголовки */
}
```

Рекомендации:
- Основной текст — `16px`, межстрочный интервал ≈1.6.
- Hero‑заголовок приветствия — `30px` display‑шрифтом.
- Не уходить в гигантские заголовки 48–60 px — для медитационного приложения это излишне агрессивно.

## 5. Сетка, отступы, формы и тени

### 5.1. Отступы

4‑пиксельная сетка:

```css
:root {
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 20px;
  --space-6: 24px;
  --space-8: 32px;
  --space-10: 40px;
  --space-12: 48px;
}
```

Применение:
- Паддинги в кнопках: `var(--space-2)`–`var(--space-3)`.
- Внутренние отступы карточек: `var(--space-4)`–`var(--space-5)`.
- Межсекционные отступы: `var(--space-6)`–`var(--space-10)`.

### 5.2. Формы и радиусы

```css
:root {
  --radius-sm: 8px;    /* инпуты, мелкие бейджи */
  --radius-md: 16px;   /* карточки, модалки */
  --radius-lg: 24px;   /* крупные блоки/контейнеры */
  --radius-pill: 999px; /* чипы, большие кнопки */
}
```

Правило: 1–2 радиуса + pill на всё приложение, чтобы дизайн не выглядел «резиновым» и хаотичным.

### 5.3. Тени

```css
:root {
  --shadow-soft:    0 8px 24px rgba(0, 0, 0, 0.06);
  --shadow-elevated:0 12px 32px rgba(0, 0, 0, 0.10);
}
```

- `--shadow-soft` — карточки, панель выбора медитаций.
- `--shadow-elevated` — модалки/диалоги (например, подтверждение выхода из медитации).

Тени мягкие, не используются как декоративный элемент, только как признак лёгкой возвышенности.

## 6. Компоненты в духе ашрама

### 6.1. Кнопки

#### Токены размеров

```css
:root {
  --btn-height-md: 44px;
  --btn-padding-x: 20px;
}
```

#### Виды кнопок

1. **Primary** — главное действие (старт медитации, продолжение практики):
   - фон: `var(--color-primary)`;
   - текст: `var(--color-text-on-accent)`;
   - радиус: `var(--radius-pill)`;
   - hover: `var(--color-primary-hover)`;
   - active: `var(--color-primary-active)`.

2. **Secondary** — второстепенные действия:
   - фон: `var(--color-primary-soft)`;
   - текст: `var(--color-primary)`;
   - без бордера или бордер `var(--color-primary-soft)`;
   - радиус: `var(--radius-pill)`.

3. **Ghost** — поверх видео (режим фокус / минимальный UI):
   - фон: `rgba(0, 0, 0, 0.24)`;
   - текст: `#FFFFFF`;
   - лёгкая тень для читабельности.

На каждом экране — максимум **одна** Primary‑кнопка, остальные визуально тише.

---

### 6.2. Карточки медитаций

- Фон: `var(--color-surface-alt)`.
- Бордер: `1px solid var(--color-border-subtle)`.
- Радиус: `var(--radius-md)`.
- Паддинг: `var(--space-4)`–`var(--space-5)`.
- Структура:
  - название (цвет `--color-text`, размер `--font-size-md` или `lg`),
  - длительность (цвет `--color-text-muted`, `--font-size-sm`),
  - краткое описание (1 строка, muted),
  - бейдж типа (`audio`, `video`, `timer`) — фон `--color-primary-soft`, текст `--color-primary`.

---

### 6.3. Круговой таймер

- Внешний круг: stroke `--color-primary-soft`.
- Прогресс: stroke `--color-primary`.
- Центр:
  - время крупно (`--font-size-xl`),
  - подпись типа «минут осталось» (`--font-size-sm`, `--color-text-muted`).
- Подложка под таймер: полупрозрачный прямоугольник
  `background: rgba(249, 246, 238, 0.92)` (из `--color-bg`).

---

### 6.4. Видео‑фон и оверлей

Компонент `VideoBackground` имеет три слоя:

1. **Видео или постер**: кадры ашрама, прогулки, холмов.[web:51]
2. **Оверлей** — затемнение/кремовый градиент, чтобы текст и UI читались на видео:[web:9][web:12][web:14]

```css
.video-overlay {
  background:
    radial-gradient(circle at center,
      rgba(0, 0, 0, 0.40),
      rgba(0, 0, 0, 0.70)
    );
}
```

или более светлый вариант для дневных сцен:

```css
.video-overlay-soft {
  background:
    radial-gradient(circle at center,
      rgba(249, 246, 238, 0.75),  /* Ashram White с прозрачностью */
      rgba(242, 229, 207, 0.95)   /* Ashram Cream */
    );
}
```

3. **Контентный слой** — таймер, текст, кнопки.

На любых сценах с видео оверлей обязателен, чтобы сохранить спокойную читаемость текста.

## 7. Тематические сцены (виртуальное погружение)

### 7.1. Welcome (прибытие в ашрам)

- Фон: `--color-bg` + лёгкий сверху градиент `Ashram Sun 500 → Terracotta 500`.
- Текст: `--color-text`.
- Основная кнопка: Primary (Ashram Sun).
- Видео: общий план ашрама на рассвете или закате.[web:51]

### 7.2. Meditation Picker (прогулка по территории)

- Фон: `--color-surface`.
- Заголовки секций: текст `--color-secondary` или тонкая линия/бордер в терракоте.
- Карточки медитаций: как описано выше.
- Видео: дорожки, деревья, мантрамп на заднем плане.

### 7.3. Session (сидим в зале/у озера)

- Фон: видео зала, озера или холмов.
- Подложки UI: полупрозрачные блоки из `--color-bg` / `--color-surface`.
- Прогресс таймера: `--color-primary`.
- Сигнал окончания: мягкий свет/пульс в цвете `--color-primary`.

## 8. Анимации и движение

- Длительность переходов: 150–240 мс.
- Easing: `cubic-bezier(0.16, 1, 0.3, 1)`.
- Типы анимаций:
  - мягкий fade‑in/fade‑out при смене экранов,
  - лёгкий `translateY(8px)` при появлении карточек,
  - плавное появление/исчезновение UI поверх видео.
- Избегать параллаксов, резких масштабирований и ярких вспышек.
- Учитывать `prefers-reduced-motion`: при включённом — минимизировать анимации.

---

## 9. Правила для команды/агента

Краткий чек‑лист использования дизайн‑системы:

1. Фон всегда светлый и тёплый (Ashram White/Cream), никаких холодных тёмных фонов.[web:48][web:51]
2. Солнце (Ashram Sun) — только для CTA и важных акцентов, не заливать им всю страницу.
3. Терракота — для заголовков блоков, бордеров, небольших декоративных элементов.
4. Зелень и вода — вспомогательные цвета; на одном экране активен максимум один из них.
5. На экране не более двух сильных акцентных цветов.
6. Любое видео всегда имеет оверлей (затемнение или кремовый градиент), текст не лежит прямо на «голом» видео.[web:9][web:12][web:14]
7. Один главный CTA на экран; остальные действия визуально второстепенны.

Эта система даёт постоянное ощущение присутствия в ашраме Art of Living: тёплые стены, солнце, терракота мантрапа, зелень холмов и мягкий свет восхода или заката над центром.[web:42][web:43][web:48][web:51]
